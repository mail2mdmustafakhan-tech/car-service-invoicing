{# A column heading you can click to sort by. It is a plain link, so it works with the keyboard, opens in a new tab if somebody middle-clicks, and survives JavaScript being blocked. The whole state lives in the query string, which means a sorted list can be bookmarked or sent to somebody and arrives sorted the same way. Clicking the column you are already sorted by reverses it. Clicking a different one starts that column ascending -- not whatever direction the previous column happened to be in, which is disorienting: the list jumps to the bottom of the new ordering for no reason the reader can see. Any other filters on the page (the search box, "show inactive") are carried through, because re-sorting a filtered list should not quietly drop the filter. #} {% macro sort_th(key, label, numeric=False, extra={}) -%} {% set active = (sort == key) %} {% set next_dir = 'desc' if (active and sort_dir == 'asc') else 'asc' %} {% set params = [] %} {% for name, value in extra.items() if value %} {% set _ = params.append(name ~ '=' ~ value | urlencode) %} {% endfor %} {% set _ = params.append('sort=' ~ key) %} {% set _ = params.append('dir=' ~ next_dir) %} {{ label }} {# An arrow only on the column actually in use. One on every heading is noise, and it tells you nothing about which one is doing the sorting. The arrow points the way the list runs, not the way clicking would take it. #} {% if active %} {{ '↑' if sort_dir == 'asc' else '↓' }} {% endif %} {%- endmacro %}
